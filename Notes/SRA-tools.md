# SRA-tools

## What is SRA-tools?
SRA-tools is an NCBI software package used to download sequencing data from the Sequence Read Archive (SRA).

## Main Uses
- Download sequencing data from NCBI SRA
- Convert `.sra` to `.fastq`
- Validate downloaded files

## Common Commands

```bash
prefetch SRRxxxxxxx
fasterq-dump SRRxxxxxxx
```

## Easy Reminder
SRA-tools = Download sequencing data from NCBI SRA → Convert to FASTQ.
